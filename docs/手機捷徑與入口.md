# 手機入口：怎麼把想法丟給阿福

目標：在手機上一句話，就進 `inbox/`。三種方式，先挑最順手的。

## A. GitHub App（零設定，最快）
1. 手機裝 GitHub App，登入。
2. 開 `jointoenjoy/afu-brain` → `inbox/` → 新增檔案。
3. 檔名隨意（例如 `想法.md`），貼上內容、commit。

## B. iOS 捷徑（一鍵丟，建議自用）
1. 內建「捷徑」App → 新增捷徑。
2. 動作：要求文字輸入 → 用「取得 URL 內容」對 GitHub Contents API 發 PUT，把文字寫進 `inbox/`。
3. 加到主畫面或分享表單，之後選取任何文字都能一鍵丟給阿福。
（需要一把 GitHub fine-grained token，只授權這個 repo 的 Contents。實作細節可請阿福幫你產生捷徑步驟。）

## C. Telegram（最像聊天）
見 `../tools/telegram-inbox/README.md`。傳訊息給 bot 就進 inbox。

## D. 之後要給團隊：LINE
台灣團隊用 LINE 最無痛。邏輯同 Telegram（LINE Messaging API webhook → 寫進 inbox），等自用驗證 OK 再接。
