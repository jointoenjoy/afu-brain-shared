# afu-brain-shared · 阿福共用腦（團隊版）

這是「阿福」（滿福）這隻總管 agent 的**團隊共用大腦**。它不是程式，而是一堆 Markdown 文字檔；用 Claude Code 打開這個資料夾，阿福就「上線」，記得品牌、技能與做事方法。

每個同事都用**同一套共用腦**（這個 repo），但各自有一份**私人腦**放自己的工作痕跡，互不干擾。

## 兩層大腦

| 層 | 放什麼 | 在哪 |
|---|---|---|
| **共用腦（這個 repo）** | 人格規則、技能、方法、品牌理念、對外文案 | `jointoenjoy/afu-brain-shared`（全團隊讀同一份） |
| **私人腦（你自己的）** | 你的日記 `情節記憶/`、待辦 `待辦.md`、個人想法 `你的思維.md`、手機隨手記 `inbox/` | 你自己的私人 repo（各自一份） |

> 共用腦**只收「方法可公開」的東西**。數據、檢測量表、定價、財務、客戶名單、未發表規劃這些「武器」**不在這裡**，鎖在主理端的私有腦。

## 同事怎麼開始用（新同事）

1. **裝 Claude Code**，登入自己的 Claude 帳號（每人各自一份訂閱）。
2. **抓共用腦**：`gh repo clone jointoenjoy/afu-brain-shared`
3. 用 Claude Code 打開這個資料夾，直接跟阿福講話。阿福會讀 `CLAUDE.md` 載入人格與規則。
4. **建自己的私人腦**（放日記/待辦/想法）：開一個自己的私人 repo，第一次跟阿福說「幫我開私人腦」即可。

## 結構

- `CLAUDE.md` — 阿福的人格與工作規則（北極星、調性、紅線、怎麼派工）。
- `skills/` — 技能（怎麼做），一技一資料夾。
- `品牌知識庫/` — 可共用的品牌事實與方法（理念、產品、對外文案、趨勢）。
- `養腦SOP.md` — 怎麼讓阿福越用越聰明。
- `教訓.md` — 錯誤變規則，下次先讀、不再犯。
- `docs/`、`.claude/`、`tools/` — 文件、分身/hook、機制（telegram inbox 等）。

## 紅線（每個人的阿福都遵守）

1. **使用者個資**：去識別化、權限最小化，碰到先找工程把關。
2. **金流／金鑰**：會花錢的一律掛起來，等真人簽核。
3. **改大腦本身**：要動 `CLAUDE.md`／`養腦SOP.md` 一定先給人批准。

> 共用腦的改動建議走 **PR／先審再合**，避免一個人不小心改壞全團隊的共同知識。
