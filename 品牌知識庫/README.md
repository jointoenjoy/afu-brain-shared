# 品牌知識庫

練息場的單一真相來源。三大類，每類底下一個資料夾，慢慢把歷年知識倒進來。

- `品牌與科學/` — 我們是誰：使命、北極星、價值觀、品牌故事、調性語氣、視覺識別；心理學原理、研究文獻、台大諮商合作、成效數據。
- `產品與內容/` — 我們做什麼：Well、Chill、線上工具與課程；Podcast、YouTube、IG、文章與素材庫；工作坊、講師、SOP、學員回饋。
- `市場與營運/` — 我們怎麼經營：受眾 persona、企業客戶案例、競品定位；定價、提案、合作夥伴、流程、預算人力；財務、合約、個資與隱私。

原則：一個概念一個檔；每則開頭標好標籤，例如：
```
---
類型: 事實
產品線: 共用 / Well / Chill
狀態: 草稿 / 已驗證
更新: 2026-06-08
---
```
