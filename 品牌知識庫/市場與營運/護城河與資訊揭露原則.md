# 練息場的護城河與資訊揭露原則

## 護城河是什麼（什麼難複製）
護城河**不是**做事方法（skill / SOP）。外人就算知道我們怎麼做，也無法馬上複製成自己的商業模式。
真正難複製、會越滾越大的是：

1. **用戶縱貫心理／檢測數據**——長期累積、綁定真實個人與企業客戶，別人拿不到。
2. **數據飛輪**：更多用戶 → 更多身心數據 → 更準的洞察與模型 → 更好的產品 → 更多用戶。單一份數據可複製，但這個循環追不上。
3. **品牌信任**：科學實證定位、台大諮商等合作背書，靠時間與口碑堆出來。

## 重要前提：護城河成立 = 守得住數據
「數據即護城河」的前提是**守得住**。心理檢測數據一旦外洩，不只賠掉護城河，還踩到**個資紅線（法律責任）**。
→ 所以資安是存亡問題，「資安分級」skill 永遠優先。數據要當保險箱來顧。

## 資訊揭露原則（一句話：方法可公開、數據與武器要鎖）

| 可以公開（外流風險低） | 必須鎖住（私有／機密） |
|---|---|
| 做事方法、SOP、agent skill、工作流藍圖 | 用戶個資與心理檢測數據（紅線一） |
| 品牌理念、北極星、團隊組織說明 | 檢測量表本身、評分算法 |
| 對外溝通用的 brief（如 aiflow 滿福頁） | 客戶名單、企業合作細節 |
| | 定價策略、未發表的產品規劃 |
| | 金鑰、帳單（紅線二） |

## 阿福做決策時怎麼用這條
- 要把任何東西放上公開頁（Cloudflare sandbox）前，先對照右欄：屬於「要鎖」的一律不放。
- 「方法／藍圖」可以攤給團隊甚至外部看，幫助溝通與管理，不必怕被學走。
- 任何碰到用戶資料、檢測數據、金流的動作，回到三條紅線，先問大寶。
