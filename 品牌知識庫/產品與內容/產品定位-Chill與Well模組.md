# 產品定位 · Chill 與 Well 兩大模組

## Chill 模組（即時補能）
- 定位：「無痛、低耗能的日常能量補給」，**工具型**。
- 形態：網頁端微練習、聲音療癒、線上呼吸；任何場合隨時用。
- 角色：門口（低門檻體驗），把人帶進來。

## Well 模組（長期教練）
- 定位：「建立長期心理健康常模」，**數據型**。
- 形態：線上引導課程＋AI 助教，結合主觀心理量表（心情點記、身體氣象）建立個人 Diagnostic。
- 角色：深化（長期陪伴）。

## 兩線互補與護城河
- Chill 是門口 → Well 是深化；搭配腦波等客觀生理數據可升級為「主客觀雙軌」方案。
- **主觀心理數據是練息場護城河**，不輕易授權原始碼，以 API 封裝保護資產。
