# AI 開發與設計工作流

## AI First 開發工作流核心
- 由 AI 控制流程與寫 Code，取代「工程師人工套版」。初期「本機終端機＋訂閱制工具」取代上雲，嚴控 AI Token 成本（「客家模式」）。
- 前端部署：**GitHub + Cloudflare 聯動**——免費、上版約一分鐘、AI 友善（全程 Git），依 Branch 自動生成子網域（sandbox / production）。
- 自動化測試：Playwright + AI 白話腳本，每次上線前重跑所有 Pass Cases，出錯直接修或回滾。
- 算力原則：**不讓 AI 做算術**（易錯），讓 AI 寫程式跑統計，再由人驗證後端結果。
- API 安全邊界：外部合作方只給 API Specification 文件，不開放後端直接存取。

## Figma Make 設計 AI 心法
- **0→1 是 AI 強項**：給 sitemap 長出全站 wireframe，一句話改框架，快速視覺化。
- **1→100 靠人類專業**：有 UX、系統架構、設計系統背景的人接手細修，產出比沒有的快好幾倍。
- 個人品味是決定因素；AI 是對話夥伴非代工機器，核心在「對話→修正→提煉思考」。
- 同一工作檔內操作才有上下文；prompt 要語意清晰＋結構明確。
- **Design System 是品質的放大器**——結構化設計系統越完整，AI 產出越準。
