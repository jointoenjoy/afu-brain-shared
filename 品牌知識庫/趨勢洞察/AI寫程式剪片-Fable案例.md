# AI 寫程式剪片 — Fable 發表影片全自動化

> 鉤子：一支正式發表影片，全程沒開任何剪輯軟體，AI 自己寫程式剪出來。人只做兩件事——丟素材 ＋ 一句話。

## 背景
Claude Code 團隊的 Thariq 揭露：Fable 發表影片是 AI 自己剪的。他做的只有——把 **17 個拍攝版本**全丟進一個資料夾（連哪段對應哪個畫面都沒標），然後**打一句話**交代。剩下全是 AI 自己跑。

## 五步（每步最神的地方）
1. **逐句轉文字（命根子）**：25GB 影片丟給電腦裡一個免費聽寫工具，產出「哪句話、第幾秒到第幾秒」的清單。這份**結構化清單是後面整套的 single source of truth**。
2. **分身平行挑鏡頭**：一次開好幾個小助手各自讀清單，自動剔除「嗯/啊/結巴」廢片，挑最順、結尾最乾淨的；列**對照表**（哪段選哪個、為什麼、用到第幾秒），再叫免費接片工具照表粗剪。
3. **調色，AI 自己弄**：他對調色完全外行，AI 自己寫出「畫面要調成什麼色」的設定，還順手做一個**有滑桿的小網頁**讓他拉，拉好數字自動傳回。→ 連工具都幫你現做。
4. **動畫卡點**：把靜態設計圖用「寫網頁」的方式做成動畫，對著第一步的逐字清單，**念到某個字（如「right」）畫面就剛好跳出**，零手動對時間。
5. **收尾輸出**：設計師把畫面改得更好看，AI 自己把新版同步回來，直接輸出 4K 成片。

## 心法（可遷移）
- **人只給「原料 ＋ 一句話意圖」，AI 自己拆步驟、自己造工具、自己平行跑。**
- **先建一份結構化的 single source of truth**（逐句＋時間碼清單），所有下游步驟都掛在它上面——跟我們知識庫 INDEX、skill description 同一個思路。
- **AI 不只「用工具」，還「現做工具」**（滑桿小網頁）。
- **用程式碼當通用介面**：剪片、調色、動畫全用寫 code／網頁的方式做。
- 印證了我們剛建的「總指揮 ＋ 平行分身、只回對照表（結論）」架構。

## 對練息場的啟發
- 正中北極星：人出創意與品味（設計師最後把關美感），AI 把「工」做掉。
- 可直接套用在 Chill/Well 的活動影片、社群影音：走「丟素材 ＋ 一句話 → 自動剪輯」流程。
- 大寶想**週一實作這套**；可執行的實作清單另查官方細節後補。
