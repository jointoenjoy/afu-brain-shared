# 民調縮影（合成民調 / 虛擬使用者測試）

> 用一小群「代表性合成市民」當廉價風洞，讓阿福在花真錢做真人調查前，先對網站、線上課程、腳本、視覺、UX、文案或剛發想的 idea 跑一輪快測，拿到方向性訊號＋風險預警。
> 靈感來自 Opus 4.8 Build Day 的 Sim Francisco（用人口資料造合成市民做秒級民調）。

## 一句話
給一個產物或問題 → 阿福讓一組「加權代表 panel」各自反應、打分 → 加權彙整成 topline ＋分眾差異＋代表心聲＋風險。**幾秒、幾乎不花錢、可重複比較。**

## 什麼時候用（適合）
- A/B 取向選擇：兩版文案／視覺／首頁，哪版對某族群更打中。
- 早期 idea 篩選：點子值不值得做、誰最買單、最大障礙是什麼。
- UX／流程預檢：某步驟會不會卡、會不會放棄。
- 課程／腳本／題詞：對目標族群會不會無聊、哪段會想關掉。
- 找「該問誰、該問什麼」：跑完合成民調再去設計真人調查的題目與對象。

## 什麼時候不要用（紅線與限制）
- **不能取代真人**：產出是「in silico 原型訊號」，不是真實消費者。**會花錢、會對外、要拍板的決策，一律拿合成結果當假設，再用真人小樣本驗證。**
- **敏感／認同題少用**：政治立場、性別／族群／身分認同這類題，合成樣本與真人落差大、又容易強化刻板印象——這種題只當參考、明確標註不可信。
- **別報假精準**：合成數字會跑來跑去。報「方向＋區間＋信心」，不要報「68.4%」這種假小數點當定論。
- **不碰個資**：panel 全是**合成虛構人物**，不是真實學員資料；嚴禁拿真人 raw data 餵進來造 persona（那會踩個資紅線一）。

## 核心方法：聰明收斂（省 token 的關鍵）
> 心法②：Sim Francisco 把 1 萬市民收斂成 ~300 代表人物，準度不掉、成本砍一兩個數量級。我們做得更省。

1. **小而代表的加權 panel**：不模擬上萬人，而是設計 ~10–16 個「交叉具體」的原型人物，各帶一個**人口權重**（加總=1），存成 `*-panel.json` **一次做好、永久重用**。
2. **一次推論掃全 panel**：跑民調時，**把整個 panel ＋產物 ＋問題放進同一次推理**，讓阿福一次預測每個人的反應＋0–100 傾向分＋一句心聲——**一題一次推論，不是一人一次**（這是省 token 的核心，別 fan-out 成幾十次呼叫）。
3. **加權彙整**：用權重把個別傾向分加總成 topline，並列出分眾差異。
4. **可重用、可比較**：同一個 panel 跑 A 版與 B 版，差異才有意義（控制變因）。

## 怎麼跑（阿福的步驟）
1. 選 panel：用哪個 `*-panel.json`（沒有對的就先快速擬一個，請大寶看權重合不合理）。
2. 給材料：貼上要測的產物（截圖描述／文案／流程／idea 一段話）＋一個明確問題。
3. **題目去除社會期許**（研究建議）：問「你會不會用／點哪個／第一個想關掉的是哪段」這種具體行為，少問「你覺得這好不好」這種會講場面話的題。
4. 一次推理輸出（見下「輸出格式」）。
5. **看情況加驗證**（心法①，預設關，高風險才開）：
   - **對抗一輪**：再派一隻「唱反調」分身，假設結論是錯的、專挑「這群人其實不會買單」的反例。
   - **回測**：拿一個已知的真實結果（如過去活動報名率、某次問卷）讓 panel 事後預測，對得上才採信這個 panel。

## 輸出格式（固定，方便比較）
```
🎯 測什麼：<產物＋問題一句話>     panel：<檔名>     信心：高/中/低
── Topline ──
主要指標（如「會在手機上實際用」）：約 XX%（區間 XX–XX%）
── 分眾差異（誰買單、誰不買）──
• <族群>：<傾向分> — <一句為什麼>
…
── 代表心聲（3–5 句，正反都要）──
「…」—<人物標籤>
── 風險／反對票（對抗視角）──
• <最大採用障礙>
── 建議下一步 ──
• 改什麼 / 該拿哪題去問真人
```

## panel 檔案（資料與真相）
- 每個 `*-panel.json` 含：`母體`、`資料基準`、`注意`，與一組 `personas`（`id`、`標籤`、`權重`、`輪廓`、`數位熟悉度`、`身心態度`、`主要痛點`、`採用障礙`、`觸發點`）。
- **輪廓要交叉具體、不要臉譜化**（研究教訓：別把一個族群壓扁成刻板印象）。
- 權重盡量貼近真實人口分布；數字是**約值**，標來源、會過時就更新。
- 內建兩個起手 panel：`台灣母體-panel.json`（一般消費者縮影）、`高科技產業-panel.json`（你 HRV App 的目標族群）。

## 信任聲明（每次產出都帶一句）
這是合成樣本的方向性訊號、不是真人民調；中性偏好題較準、敏感題不可信；要拍板或對外前請用真人小樣本複驗。

## 研究依據（2026-06 輕量查證）
- 合成受訪者可達真人信度約 90%、分布相似度 >85%（中性消費題）。
- 已知陷阱：敏感／認同題落差大、子群體易被壓扁成刻板印象、跑次間會飄、上下文過多會誇大極端 → 本 skill 以「固定小 panel＋報區間＋對抗驗證＋真人複驗」對沖。
