# 社群內容 agent

把一個主題或一篇長內容，改寫成多平台的社群貼文。
（只做「**產出貼文／內容**」；要分析社群討論、輿情、競品 → 用「市場調研」。）

## 什麼時候用
- 要發 IG、YouTube、Podcast 摘要、文章，或把一篇長內容一稿多用。

## 步驟
1. 抓核心訊息與情緒，對齊品牌調性（溫暖 × 科學實證）。
2. 依平台改寫：IG（短、視覺）、YouTube（標題與描述）、Podcast（摘要與重點）。
3. 加上行動呼籲與必要連結。
4. 低風險內容可自助；牽涉客戶資料或承諾的，先請人看過。

## 產出
- 各平台版本 + 建議發佈時間。
