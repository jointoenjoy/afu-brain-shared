# Figma 完稿交付清單（給設計師 · 為了讓 AI 接手量產內頁）

> 給設計師的話：感謝你操刀首頁的視覺與調性。接下來的內頁，我們會用 AI 依你定的首頁系統來量產。
> 所以這份交付的重點是：**完稿不只是「一張漂亮的設計稿」，而是「一套機器讀得懂的設計系統」。**
> 你把系統做得越清楚，AI 產出的內頁就越像你設計的、越不走鐘。下面分「最重要的三件事」＋細部清單。

---

## 先記三件最重要的（其他都是延伸）
1. **顏色、字體、間距都用 Variables / Styles 設成「變數」**，不要每個圖層各自填 hex。
2. **重複出現的東西做成 Component（元件）**：按鈕、卡片、導覽、footer、表單。
3. **圖層命名要有語意**（`btn / primary`、`card / course`），用 Auto Layout 排版，不要散圖層硬拼。

做到這三件，這份清單就成功八成了。

---

## 一、檔案結構與命名
- 一個頁面一個 Frame，Frame 命名清楚（`Home / Desktop`、`Home / Mobile`）。
- 圖層用**語意命名**：`btn / primary`、`section / hero`、`card / course`，不要 `Rectangle 28`、`Group 12`。
- 用 **Auto Layout** 組版（區塊、卡片、按鈕內部都用），不要絕對座標硬擺。
- 完稿前清掉：隱藏圖層、廢棄草稿、命名混亂的殘件。

## 二、設計系統 Tokens（最關鍵，AI 的規格書）
- **顏色**：全部設成 **Color Variables / Styles**，語意命名（`color/brand/primary`、`color/bg/soft`、`color/text/body`）。對齊練息場品牌色票（主藍 `#004D89`、深藍 `#003864`、柔調底 `#E5EDF3` 等，鮮彩只當點綴）。**不要把 hex 直接填在圖層上。**
- **文字**：字級／行高／字重做成 **Text Styles**（`heading/h1`、`body/base`、`label/sm`）。標題用品牌主字（金萱），內文用無襯線黑體。
- **間距**：採 **8 的倍數系統**（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64），Auto Layout 的 gap 與 padding 都用這套，不要隨手抓數字。
- **圓角**：全站統一一套（例：卡片 16、按鈕膠囊），不要一頁好幾種。
- **陰影 / 效果**：做成 **Effect Styles**，別每個元件各調各的。

## 三、元件化 Components
- 重複的 UI 做成 **Component + Variants**：按鈕、卡片、導覽列、footer、表單欄位、tag、輸入框、頭像。
- 元件用 Auto Layout，能隨內容自動撐大（讓 AI 知道它是彈性的）。
- 標出**互動狀態**：default / hover / active / disabled（按鈕、輸入框尤其要）。

## 四、RWD 響應式
- 至少交 **桌機（1440）＋ 手機（375）** 兩個版型。
- 標清楚：窄螢幕時哪些元素**隱藏 / 換行 / 改成上下堆疊**。

## 五、互動與動態的標註
- 不用做成可點的 prototype，但**關鍵動態用註解寫清楚**：哪裡要動（hero 進場、滑動浮現、hover 回饋）＋**「為什麼動」**（引導視線 / 敘事節奏 / 點擊回饋）。
- 練息場是療癒品牌，動態偏**克制、緩慢**，避免炫技。

## 六、內容與素材
- 文案用**真實或接近真實**的內容，不要 Lorem ipsum 或「標題標題標題」（AI 會照著生假掰文字）。
- 圖片：給真實圖，或標好**尺寸＋用途**的佔位（`course cover 16:9`、`avatar 1:1`）。
- icon：用**一套 icon set**（別手刻零散圖示），標明來源。
- 可匯出素材：**logo 給 SVG**、圖片切好可下載。

## 七、完稿時請給我這些（交付物清單）
1. Figma 檔的**檢視連結**（開 Dev Mode / 可讀權限）。
2. 一頁 **Style Guide 頁**：把色票、字體、間距、所有元件攤開展示。
3. 桌機＋手機**兩個版型**，斷點行為標註。
4. **素材匯出**：logo（SVG）、圖片、icon。
5. 一段話：**設計概念與調性說明**（讓 AI 抓對品味方向）。

---

## 會讓 AI 產出「走鐘」的雷（請避開）
- ❌ 顏色直填 hex、不用變數 → AI 抓不到系統，每頁顏色會飄。
- ❌ 同功能元素長得不一樣（三種按鈕樣式）→ AI 不知道哪個是標準。
- ❌ 把文字壓平成圖、純圖片拼貼 → AI 讀不到文字與結構。
- ❌ 圖層命名亂、隱藏圖層一堆 → AI 誤判版面。
- ❌ 只給桌機、沒給手機 → 內頁 RWD 只能用猜的。

> 一句話：**你把首頁做成「有系統、可讀」的樣子，AI 就能把內頁產得又快又像你設計的。**
